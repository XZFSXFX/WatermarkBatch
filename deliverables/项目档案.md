# 项目档案 · 水印工坊 BatchMark

## 基本信息
- **项目名称与一句话定位**：水印工坊 BatchMark——iPhone 相册照片 / Live Photo / 动图 / 视频「批量一键」加水印：不缩图、不压缩画质、不改输出格式，处理完原样存回相册。
- **平台选型**：iOS 原生 SwiftUI（iOS 17+）。小程序 / Web / Flutter / RN 经能力矩阵逐项核对均为「不可行」（无法读 PHAssetResource 原文件、无法配对 Live Photo、无法原格式写回视频、无法批量写相册）——平台红线，不可绕过。
- **技术栈**：Swift 6 / SwiftUI / PhotoKit / AVFoundation / VideoToolbox / Core Image + Metal / CGImageSource&Destination / BGTaskScheduler；零第三方依赖、纯本地不联网。
- **使用形态**：个人自用、侧载安装，不经任何应用商店（无审核、无 TestFlight、无账号体系、无云服务）。
- **当前阶段**：Phase 1 ✅ → 代码实现（块A/B/C 已落盘，**待编译**：54 个 Swift / 约 13,171 行，Windows 环境无 Xcode，未经任何编译）→ 测试方案 ✅ → 装机指南 ✅ → 待 Mac 首编译 + 真机验收。

## 架构决策摘要
- 视频导出管线：**AVAssetReader + AVAssetWriter 手动管线**（码率/profile/level/HDR 参数全部显式可控）；禁用 AVAssetExportSession 与任何预设。
- 预览与导出同管线：统一入口 `WatermarkCompositor.compositedFrame(seconds:)`，四类预览与导出共用同一合成函数；预览仅允许降采样显示，几何用同一 `pixelsPerPoint` 换算。
- Live Photo 拆解配对为 P0 红线：HEIC MakerApple 17 键 + MOV content.identifier 同一 assetIdentifier，`PHAssetCreationRequest` 以 (.photo, .pairedVideo) 资源对写入；严禁降级为静态图/普通视频。
- 音频 passthrough：压缩 CMSampleBuffer 直写，不重编码、不改采样率声道。
- 并发：唯一闸门 `ConcurrencyLimiter`（actor，photo/video 分通道）；默认 2 照片 / 1 视频，视频恒不并跑。
- 内存：>256KB 的图片产物由 BatchQueue 落 tmp 转 `.imageFile` 释放 Data（03 §4 v1.2），避免批量产物线性驻留。

## 默认参数（画质优先档，写死常量）
| 项 | 值 |
|---|---|
| 缩放 | 无（输出尺寸 = 输入尺寸） |
| JPEG / HEIC / WebP 质量 | 1.0 |
| PNG | 无损、保 alpha、不量化 |
| 视频码率 | max(源 × 1.3, 平台推荐) |
| 视频编码器 | 严格同源（avc1→H.264，hvc1→HEVC） |
| profile / level | 不低于源，导出后回读校验 |
| GOP | 与原文件相近（0.5–10s） |
| 并发 | 照片 2 / 视频 1 |
| 唯一降级开关 | 「优先速度」：码率 ×1.0、JPEG 0.95、并发 3-4 |

## 技术债务与已知边界
- 全部代码在 Windows 产出，**未经 Xcode 编译**；首编译需修少量 strict concurrency 标注。
- 视频为「视觉无损」（PSNR≥42dB / SSIM≥0.98），非数学无损。
- RAW/DNG 无法内嵌水印 → HEIC 输出，处理前显式告知。
- HEIC 二次编码有轻微损失；提供「输出 PNG 无损」勾选（容器改变、体积 6-10 倍、部分元数据可能不随 PNG 保留，缺失分组写入日志与记录）。
- GIF/WebP 调色板 ≤256 色，叠水印后必量化，平滑渐变可能色带。
- 四项真机验收未做：Live Photo 长按播放、GIF 逐帧延时一致、4K HDR 未降级、音频 passthrough。
