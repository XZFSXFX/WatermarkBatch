## 一、产品定位与命名

**一句话定位**：一款 iOS 原生「批量·无损·极速」相册水印工具——把文字或 Logo 水印一次性加到任意数量的照片、Live Photo、动图和视频上，不缩图、不压画质、不改格式，原图只读不破坏。

**App 命名建议**：
- **中文名：水印工坊**
- **英文名：BatchMark**

命名理由：「工坊」传达精工细作、不损原片的专业感，对冲"水印 App 都会压画质"的用户固有疑虑；「BatchMark」直指核心场景（Batch 批量 + Mark 水印），搜索友好、无商标冲突风险（上架前需在 App Store Connect 与商标库复核）。

**价值主张三支柱**（全部为产品红线，任何一柱倒塌则产品核心价值不成立）：
1. **无损**：原编码器、原色彩空间、原位深、原 EXIF 全保留；JPEG 质量 1.0 不缩放；PNG 保留 alpha；视频视觉无损（PSNR≥42dB / SSIM≥0.98）。
2. **批量**：混合类型多选、一键套用、3-4 并发按内存自适应、失败不阻断、锁屏不中断。
3. **极速**：iPhone 12 起，4000×3000 JPEG×30 张端到端 ≤8s；预览拖动 ≥55fps；点水印到画面 <100ms。

**不做清单（负向）**：云端同步、账号体系、社交分享、广告、内购、滤镜、AI 抠图——一概不进任何版本。

## 二、目标用户与使用场景

### 2.1 背景
摄影师、电商运营、自媒体博主每天需要给成百张原片打版权水印或品牌 Logo。现有方案两大痛点：① 大多数工具导入即重新编码压缩、EXIF 丢失、HEIC 被转成 JPEG；② 只能逐张处理，视频/Live Photo/动图要么不支持要么导出后降级（Live 变静图、GIF 丢透明、HDR 视频变 SDR）。本产品以"格式原样保留 + 批量一键"为差异化切口。

### 2.2 目标用户

| 用户群 | 核心诉求 | 典型素材 |
|---|---|---|
| 摄影师/图片库供稿人 | 版权保护，EXIF 与画质是交付红线 | RAW/JPEG/HEIC 大图、4K 视频 |
| 电商运营/美工 | 品牌 Logo 批量贴图，模板复用 | PNG 透明 Logo + 千级商品图 |
| 自媒体/短视频博主 | 视频与 Live Photo 打标且不损 HDR | HEVC 10bit/Dolby Vision 视频、GIF 动图 |
| 普通用户（隐私动机） | 给要外发的照片批量加"仅供 XX 使用" | 日常照片混合批次 |

### 2.3 目标与北极星指标

- **业务目标**：App Store 上线首月 ≥5,000 次下载、评分 ≥4.6；
- **北极星指标**：**周均成功导出水印素材数/活跃用户**（人均，本地统计匿名上报口径）；
- **成功度量**：
  - 首月核心闭环完成率（导入→导出成功）≥ 70%；
  - 单次批量会话平均处理素材数 ≥ 20；
  - 导出失败率 ≤ 2%，其中格式降级类失败（P0 缺陷）= 0；
  - 批量导出后次日回访率 ≥ 30%。

### 2.4 核心用户故事（摘要版，验收标准见第三章功能清单）

| 编号 | 故事 | 角色 | 优先级 |
|---|---|---|---|
| US-01 | 我要一次性勾选 200 张混合了照片/Live/GIF/视频的素材，按日期分组别让我翻找 | 摄影师 | P0 |
| US-02 | 我要拖动、旋转、微调水印到精确位置，照片上实时看到最终效果 | 电商美工 | P0 |
| US-03 | 视频拖时间轴时水印必须真实渲染在当前帧上，不能"大概示意" | 短视频博主 | P0 |
| US-04 | 我要一键把这批 500 张图全部套上水印，失败了告诉我哪张为什么，别中断 | 电商运营 | P0 |
| US-05 | 导出后格式、画质、EXIF、Live Photo 可播放性必须和原来一模一样 | 摄影师 | P0 |
| US-06 | iCloud 里的原图要下载进度可见、可重试，别偷偷用缩略图糊弄我 | 摄影师 | P0 |

## 三、功能清单（P0/P1/P2）

**优先级判定采用三问法**：砍掉它核心闭环能否走通？→ 走不通即 P0；缺失时闭环可走通但显著伤体验 → P1；推迟无伤 → P2。
**P0 统计：15 项 / 共 29 项 = 51.7% ≤ 60%，符合红线**。每项验收标准均为可测量条件。

| 编号 | 功能 | 优先级 | 判定理由 | 验收标准（可测量） | 关联故事 |
|---|---|---|---|---|---|
| F-01 | 相册混合多选导入：照片/Live/GIF/视频/RAW，日期倒序分组，类型角标 | P0 | 无导入则无闭环 | 混选 5 类素材各 ≥1 可一次勾选；分组按拍摄日倒序；角标标识与实际 PHAsset 类型一致率 100% | US-01 |
| F-02 | iCloud 原图下载：进度可见、可重试、不静默降级 | P0 | 降级即违背无损支柱 | 下载进度 0-100% 实时刷新；网络中断显示重试按钮；下载失败素材进入失败清单而非静默用缩略图处理 | US-06 |
| F-03 | PHCachingImageManager 列表预缓存 | P1 | 滚动流畅是体验优化，缺失可走通 | 200 素材列表滚动不出现白块占比 >95%；CPU 峰值 <40% | US-01 |
| F-04 | 文字水印：内容/字体/字号/颜色/描边/阴影/不透明度/字间距 8 参数 | P0 | 文字水印为最小可用水印 | 8 参数全部实时反映到预览（<100ms）；参数值数值化显示可回读 | US-02 |
| F-05 | 图片水印：导入 PNG 透明 Logo 保留 alpha | P0 | Logo 是半数目标用户刚需 | 50% 半透明 PNG 导入后边缘无白底、无锯齿毛边；alpha 通道保留 | US-02 |
| F-06 | 位置控制：九宫格快速对齐 + 单指拖拽 + 双指缩放/旋转 | P0 | 无位置控制水印无意义 | 九宫格 9 宫位点击即吸附到位；拖拽跟手 ≥55fps；双指旋转 0-360° 连续 | US-02 |
| F-07 | 数值微调：X/Y 偏移 px、缩放 %、旋转角度 0.1° 步进 | P0 | "精确"是差异化卖点，只给拖拽不达标 | 数值输入与画布位置双向同步；旋转步进 0.1°；数值显示与实际渲染位置误差 = 0 | US-02 |
| F-08 | 边缘安全区吸附：自动避让刘海/圆角/灵动岛安全区 | P1 | 缺失时仍可手动微调补救 | 水印拖入安全区外 20px 内自动吸附；吸附后蓝色高亮提示；可一键关闭吸附 | US-02 |
| F-09 | 水印模板：保存当前全部参数（含图片水印），批量套用 | P1 | 闭环可走通，但电商复购场景显著提效 | 模板保存含全部 8 参数+位置+Logo；重新套用还原误差=0；≥10 个模板容量 | US-07 |
| F-10 | 平铺模式：满屏半透明重复平铺，默认关闭 | P2 | 防盗图进阶玩法，推迟无伤 | 开启后预览实时平铺渲染 ≥55fps；平铺密度/角度可调；默认状态=关闭 | US-02 |
| F-11 | 照片实时预览：所见即所得 | P0 | 预览≠导出则全链路失信 | 预览帧与导出帧逐像素一致（同一渲染管线）；点选水印到画面 <100ms | US-02 |

## 四、信息架构与关键用户流程

### 4.1 四页签导航（Tab ≤5，符合规范）

| P-02 | 水印编辑 | Tab 2 | F-04~15 | 空态：未选素材引导回 Tab1；加载态：原图下载进度环；错误态：下载失败重试；无权限态：不适用（本地渲染） |
| P-03 | 批量任务 | Tab 3 | F-16/17/27 | 空态：无任务引导；进行中：进度条+计数；错误态：失败清单；无权限态：写相册被拒引导 |
| P-04 | 导出记录 | Tab 4 | F-29/24/28 | 空态：无记录插画；加载态：列表骨架；错误态：单条记录失败原因展开；无权限态：不适用 |
| P-05 | 模板管理（编辑页内嵌二级页） | 2 | F-09 | 空态：新建模板引导 |

### 4.2 核心用户流程：选素材 → 编辑 → 预览 → 批量 → 导出 → 记录

**主流程（最短 4 步完成一次批量加水印）：**

1. **选素材**（Tab1）：勾选素材（可混类型）→ 底栏显示已选 N 项与类型分布 → 点「开始编辑」→ Tab2。
2. **编辑**（Tab2）：默认新建文字水印或选模板 → 九宫格/拖拽/双指定位 → 数值面板微调 → 照片实时所见即所得；视频类素材出现时间轴拖动预览当前帧。
3. **批量**（Tab3）：点「批量套用并导出」→ 二次确认（含预估耗时）→ 任务进入队列，逐任务进度与成功/失败计数实时刷新 → UI 不阻塞可切 Tab。
4. **导出与记录**：完成 → 结果页（成功 N / 失败 M + 失败原因清单）→ 失败项可「重试失败项」或从批次移除 → 记录写入 Tab4。

**异常分支（每步有出口，无断点）：**

- **未授权相册**：Tab1 弹引导卡 → 「打开设置」跳系统设置 → 返回后自动刷新授权状态；仅添加模式下功能全可用，仅提示无法读取历史相簿归集。
- **iCloud 未下载**：素材角标显示云朵图标 → 点击触发原图下载，进度 0-100% → 失败 → 重试按钮 → 再失败 → 该项标记失败进失败清单，**绝不静默用低清图处理**。
- **网络中断（下载中）**：进度暂停 → 提示"网络不可用，已暂停"→ 网络恢复自动续传或手动重试。
- **数据为空**：相册无素材/模板库为空/无导出记录，均有插画+引导文案，不留白屏。
- **批量中单任务失败**：跳过该项继续后续任务（不阻断），结束汇总失败清单与逐条原因（如"格式不支持导出编码器"），可一键重试失败项。
- **中途取消**：确认弹窗「已完成的 X 张将保留，未处理的不再继续」→ 取消后已完成素材在相册与记录中可见。
- **锁屏/切后台**（v1.1 起）：BGProcessingTask 续跑；v1.0 前台中断任务暂停，回前台提示继续/放弃。
- **RAW 素材**：导出确认框告知"RAW 将转 HEIC"→ 确认继续 / 移除 RAW 项重导。
- **覆盖风险**：本 App 从不覆盖原图（只读复制写入），二次确认框文案明示"将在相册新增处理后的副本，原片不被修改"。

## 五、水印编辑器交互详规（Tab 2）

### 5.1 画布与手势

| 交互 | 行为规格 |
|---|---|
| 单指拖拽 | 水印随手指移动，跟手 ≥55fps，坐标实时回显至数值面板（px） |
| 双指捏合 | 缩放水印 10%~500%，回显百分比 |
| 双指旋转 | 0-360° 连续旋转，回显角度（0.1° 精度） |
| 九宫格 | 画面九等分参考线，点选 9 宫位水印跳吸至该位中心，蓝框高亮 300ms |
| 数值微调面板 | X/Y（px，±1 步进，支持长按连调与键盘直输）、缩放（%±1）、旋转（°±0.1）；输入非法值即时红框提示并保留上次合法值 |
| 安全区吸附（v1.1） | 系统安全区（刘海/灵动岛/Home 指示条）外扩 20px 为警戒带；水印进入警戒带时吸附至安全边界并蓝光提示；设置中可关 |

### 5.2 属性面板（文字水印）

内容输入框（多行）→ 字体（系统+内置商用免费字体列表，不少于 12 款）→ 字号（pt 数值）→ 颜色（取色器+常用色板）→ 描边（宽度 0-10px、颜色）→ 阴影（X/Y/模糊半径/不透明度）→ 不透明度（0-100% 滑杆+数值）→ 字间距（em 数值）。图片水印面板含：Logo 导入、不透明度、混合模式（正常/正片叠底，v1.1 扩展）。全部参数调整即时反映到画布，延迟 <100ms。

### 5.3 预览行为（红线：预览渲染与导出渲染同一管线）

- **照片**：实时所见即所得；双指缩放画布查看 1:1 细节（水印随内容同步缩放）。
- **视频**：底部时间轴滑块，拖动时按 30/60fps 以真实解码帧渲染水印位置与尺寸；播放按钮可连续播放预览。
- **Live Photo**：切换「静帧 / 动态段」两个预览位分别确认水印落位。
- **GIF**：首帧/中间帧切换 + 帧数标签。
- **平铺模式**（v2.0）：开关默认关闭，开启后画布实时平铺预览。

### 5.4 模板与时间段

- 模板：右上「存为模板」保存当前全部参数与 Logo，模板管理页支持重命名/删除/应用；批量套用时选中素材全量应用。
- 时间段（v1.1）：视频水印出现区间选择「全程 / 自定义起止」，起止点通过时间轴把手拖动或数值输入（秒，0.1s 精度），预览即时反映边界。

## 六、版本路线图与数据埋点

### 6.1 版本路线图（iOS 单端，范围不重叠）

**V1.0 MVP（开发期 8~10 周）**
- 目标：跑通「导入→编辑→预览→批量→无损导出→记录」核心闭环，验证口碑。
- 范围：全部 P0（F-01/02/04/05/06/07/11/12/16/18/19/21/23/25/26）+ 少量决定转化/安全的 P1：F-27（二次确认+预估耗时）、F-22（RAW 告知弹窗文案随 v1.0 上，告知属合规底线；完整 RAW 处理链路可后续完善）、F-29（导出记录基础版，闭环收尾反馈）。
- 性能门禁（上线标准，iPhone 12 实测）：4000×3000 JPEG×30 张端到端 ≤8s；1min 1080p30 ≤30s、1min 4K30 ≤60s；4K 内存峰值 <250MB；预览 ≥55fps；点水印到画面 <100ms；P0 缺陷=0。
- 合规项：权限文案两套、隐私政策（纯本地无采集声明）、App Store 审核材料齐备。

**V1.1（上线后 2~6 周，按 V1.0 数据决策）**
- 目标：修补留存与效率瓶颈，覆盖进阶格式与后台续跑。
- 范围（按指标触发的候选，全部为 P1 存量）：F-09 模板套用（触发：周回访用户中 ≥30% 重复编辑同类水印）、F-13 时间段（触发：视频素材占比 ≥25%）、F-17 后台续跑（触发：批量中途放弃率 ≥15%）、F-14 Live 双预览、F-15 GIF 帧预览、F-20 GIF/WebP 完整导出链路（若 v1.0 仅支持导入预览则此版补齐导出）、F-03 预缓存、F-08 安全区吸附。
- 决策规则：每个候选绑定一个 V1.0 指标阈值，未达标者顺延。

**V2.0（Q+1）**
- 范围候选（P2 存量+兴奋型）：F-10 平铺模式、F-24 智能相簿、F-28 完成通知跳转、iPad 自适应布局、混合双水印（文字+Logo 叠加层管理）。
- 原则：逐版消化不并行，全部来自 P2 存量或用户反馈 Top3。

**刻意不做（负向清单）**：云端/账号/分享/广告/内购/滤镜/AI 抠图、Android/鸿蒙端（选型结论为仅 iOS，如需扩展须团长层面重新选型）。

### 6.2 数据需求与埋点表

**数据实体（全部本地存储，无云端）**：素材批次（批次ID、素材清单、类型分布、时间）、水印配置（参数集 JSON）、导出记录（批次ID、逐素材状态、格式、耗时、失败原因）、模板（命名+参数集）。运营侧最小功能：记录页筛选（按状态/格式）与失败清单导出为文本（本地生成，供用户反馈附日志）。

## 七、权限与合规文案

### 7.1 相册权限文案（两套）

**系统弹窗（Info.plist NSPhotoLibraryUsageDescription）**：
「水印工坊需要访问你的相册，用于选取要加水印的照片和视频。所有处理均在你的设备本地完成，不会上传或修改你的原片。」

**仅添加模式弹窗（NSPhotoLibraryAddUsageDescription）**：
「水印工坊需要将加好水印的照片和视频保存到你的相册。你也可以仅授予添加权限，本功能即可正常使用。」

**App Store 隐私描述（隐私营养标签+描述页）**：
「水印工坊不收集任何数据。相册访问仅用于读取你选择的素材与保存处理结果，全程离线，原图只读不受修改，无任何第三方 SDK，无网络请求。」

### 7.2 RAW/DNG 转换告知文案（导出确认弹窗）

「本批次包含 N 个 RAW/DNG 文件。iOS 无法以原 RAW 格式写回加水的版本，它们将以 HEIC（画质无损级质量）格式保存为新副本，原 RAW 文件保持不变。是否继续？【继续 / 从本批移除 RAW 文件】」

### 7.3 视频视觉无损说明文案（导出确认框脚注/帮助页）

「视频导出策略：保持原分辨率、帧率、时长与 HDR（含 HEVC 10bit/HLG/Dolby Vision/BT.2020），音频原样直通，采用与源相同的编码器，码率取源码率 1.15 倍与推荐码率中较大者，实测视觉质量 PSNR ≥42dB、SSIM ≥0.98，达到视觉无损标准。」

### 7.4 覆盖写入确认文案

「即将处理 N 个素材并在相册创建副本（原片不会被修改或删除），预计耗时约 X 分 Y 秒（±20%）。已完成的部分不受中途取消影响。」

4. 合规文案与权限弹窗与本文第七章逐字一致；

6. 需求变更须走变更登记→影响评估→版本归属决策→用户确认→变更通知五步流程，禁止口头变更与开发中途静默修改验收标准。
